# Jiaye Li — Academic Homepage

A lightweight bilingual academic homepage built with plain HTML and CSS for GitHub Pages.

## Before publishing

1. The portrait extracted from the supplied CV is stored at `images/profile.jpg`.
2. Update matching content in both `index.html` and `zh.html` whenever adding news, publications, or experience.
3. Commit the files to the root of a GitHub Pages repository and publish from the `main` branch, `/ (root)`.

The email, Google Scholar profile, ORCID, education, honors, and publication information are based on the supplied CV. No build step or external font is required.
